# Personal Portfolio Website

A personal portfolio website built with **Django** to showcase my skills, projects, certifications, and professional journey.

## 🚀 About the Project

This portfolio website is designed to provide a simple and professional way to present my work and technical skills.

It includes:

- Personal introduction
- About me section
- Skills and technologies
- Projects showcase
- Certifications
- Responsive portfolio interface
- Django-powered backend
- Static and media file handling

## 🛠️ Tech Stack

### Backend
- Python
- Django
- SQLite

### Frontend
- HTML5
- CSS3
- JavaScript
- Bootstrap

### Tools & Technologies
- Git
- GitHub
- Django Templates
- Django Static Files
- Django Media Files
